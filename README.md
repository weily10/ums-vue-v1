# UMS Vue v1 
https://ums-vue.netlify.app/

A Vue.js recreation of selected features from a web application originally developed during my work at **UDN Digital**.

The original application was built using jQuery, JavaScript, and Bootstrap. This project recreates some of its core interfaces and functionality using Vue.js, demonstrating how the same concepts can be implemented with a modern frontend framework.

## Features

- **Dashboard:** Data-driven dashboard interface for displaying key information.
- **Forms:** Interactive forms for data input and management.
- **Data Visualization:** Interactive charts and plots integrated with Apache ECharts.

## Technologies

- Vue.js
- JavaScript
- Bootstrap
- Apache ECharts

## Project Purpose

This project serves as a frontend portfolio demonstration, showcasing my ability to recreate existing application interfaces and translate traditional jQuery-based implementations into a Vue.js architecture.

## Disclaimer

This is an independent recreation for portfolio and educational purposes. It does not contain the original company's source code, proprietary business logic, or confidential information.
